# Resume-AI

AI-powered resume analyzer and ATS optimization tool designed to help users improve resume quality and job matching.

## 🚀 Features

* Upload resume PDF
* ATS score analysis
* Skill extraction
* Resume feedback generation
* Job description matching
* AI-powered improvement suggestions

## 🛠 Tech Stack

* Python
* Streamlit
* NLP / Machine Learning
* PDF Processing
* Gemini/OpenAI API (if used)

## 📌 Project Overview

Resume-AI helps job seekers optimize resumes for Applicant Tracking Systems (ATS). The system analyzes resume content, identifies missing skills, and provides actionable suggestions to improve job matching.

## ⚡ How It Works

1. Upload resume
2. Extract text from PDF
3. Analyze skills and keywords
4. Compare with job description
5. Generate ATS score and suggestions

## ▶️ Run Locally

```bash
git clone https://github.com/Tejasri-2705/Resume-Ai.git
cd Resume-Ai
pip install -r requirements.txt
streamlit run app.py
```
